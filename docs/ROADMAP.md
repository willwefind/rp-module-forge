# Roadmap

This roadmap separates **specified**, **implemented**, **validated**, and **integrated** work. Dates are intentionally not promised while the architecture is still moving quickly.

## V0.1 — Product truth and contracts

- [x] Public monorepo skeleton
- [x] Web App chosen as primary product surface
- [x] Ancient China chosen as first official world pack
- [x] SillyTavern chosen as first first-party runtime integration
- [x] Non-omniscience / identity-permission / expert-lens / host-decision invariants specified
- [x] Eight Ancient China system names mapped to generic core capabilities
- [x] Traveler Forum promoted to first-class subsystem
- [x] Dual engineering + traveler-lore maintainer log convention
- [ ] Align current TypeScript IDs and manifest shape with V0.1 contracts
- [ ] Implement full export set from normalized config

## V0.2 — Ancient China playable foundation

- identity profiles: emperor, heir, regent/powerful minister, general, local official, scholar, merchant, commoner, servant
- resident / on-demand / disabled capability modes
- all eight core systems available through the Web builder
- expert-lens selection and disagreement rendering
- Traveler Forum thread / reply / curated-note fixtures
- curated-only and manual forum retrieval
- current-session patch with typed facts / claims
- one-line, compact, full, and manifest exports
- four-identity crisis validation scenario

## V0.3 — Forge usability

- explanation for every recommendation (“why this module?”)
- conflict and incompatibility warnings
- manifest import / export
- local presets without account or backend
- token modes: Light / Standard / Full
- on-demand module preview and temporary expansion model
- clearer implementation-status labels in UI

## V0.5 — Public Web App quality

- polished responsive visual builder
- Ancient China themed presentation without mixing lore into stable IDs
- visual prototypes for relationship graph, readiness/logistics, stakeholder signals, and Traveler Forum threads
- accessibility and keyboard navigation
- deterministic validation and migration tests
- public deployment

## V0.7 — Contributor ecosystem

- world-pack authoring specification
- contributor fixtures and schema validation
- Traveler Forum contribution templates
- pack compatibility/version rules
- first community pack experiments

## V0.8 — SillyTavern first-party integration

- manifest import
- active module sidebar
- Light / Standard / Full token policy
- temporary on-demand expansion and withdrawal
- documented injection target strategy
- per-chat / per-character persistence decision
- current-chat scope controls
- use the model already configured in SillyTavern; no second API key

## V1 — Stable first release

- stable Web App
- Ancient China Pack 1.0
- first-party SillyTavern integration
- compatibility and migration policy
- contributor pack specification
- validated cross-identity behavior

## Later world directions

The core must be able to accept new presentation and content without redesign:

- Europe / historical Europe
- fantasy
- cultivation / xianxia
- space opera / interstellar
- cyberpunk
- post-apocalypse

Ancient China is the first proof, not the permanent boundary.
