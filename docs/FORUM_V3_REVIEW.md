# Forum-first V3 试玩验收与维护说明

日期：2026-09-04。当前目标为可交互审看版本，Pages 根路径继续提供现有模块工坊。

功能提交：`751e87ba1c6de8400167e0e97c7fd3b83475a143`（`feat(forum): make V3 interactive with profiles and authored archives`）。

试玩地址：https://willwefind.github.io/rp-module-forge/prototypes/forum-first-concept-v3.html

## 值得审看的路径

1. 点「＋ 发主题」：七个中文分类均对应仓库现有的 Discussion 表单 slug。公告注明维护者发布权限。
2. 在档案柜新建、改名、编辑身份 / 路线 / 权限备注 / 私密备忘；保存后刷新、切回旧档案。去皇帝区或查看未开放世界，档案保持原样。
3. 读永宁帝复盘：正文中断有说明，回复先加载 4 条再展开为实际 8 条。没有旧版虚设的 428 楼或模拟点赞。
4. 搜「那盏灯后来还了」会命中回复所在的皇帝帖。经验卡可回到关联原帖，模块帖显示当前本局与手动配置入口。
5. 主题中的「我复现过 / 适用性存疑 / 我有补充」先打开分类选择器，将公开档案标题带到勘误表单标题。不会把本局信息、私密笔记或授权决定外发。
6. 日间、夜间、护眼切换可保存。手机保留档案管理、分类发帖与可横向浏览的分区栏。

## 实现边界

- 12 篇仓库创作主题、40 条逐帖回复；不是 12 个真人账号。每帖展示作者叙事状态、内容审阅状态、创作来源与仓库链接。
- 经验卡是展示层整理，没有新增 Runtime 自动注入规则；机器能力 ID 不变。
- 当前没有已授权的真人帖子导入，不以虚构投稿代替。真人账号、发帖、回复、通知、reaction 都留在 GitHub。
- 分类链接使用 `/discussions/new?category=<slug>`。表单绑定依据为现有 `.github/DISCUSSION_TEMPLATE/<slug>.yml`；[GitHub 官方规则](https://docs.github.com/en/discussions/managing-discussions-for-your-community/creating-discussion-category-forms)要求文件名与分类 slug 一致。登录后的实际发布由用户完成。
- 多档案使用 `td-profile-store-v4`，含 `version / profiles / activeId`。读取 V3 两个旧 key 时保留旧副本；无效结构或存储受限时不静默覆盖原数据，显示临时模式与备份提醒。
- 删除前显示档案名称并确认，最后一份禁止删除。导出包含档案柜中当前数据，不包含未提交的编辑表单；备份包含私密备忘。此版提供 JSON 导出，尚未提供 UI 导入恢复。
- 世界域浏览状态与档案完全分离；只有「东方古代 · 架空王朝」可新建选择。旧版档案中的自定义世界文字可保留，但不代表对应世界包开放。
- 论坛附件到工坊是手动配置入口，尚无一键安装或跨页面档案自动同步。工坊增加返回 V3 链接。
- `prototypes/forum-v3/` 内为独立内容、纯逻辑、页面交互与样式。Pages 递归复制 prototypes，避免只复制 HTML 造成模块资源 404。
- 旧原型与现行产品的知识层显示名统一为「老乡经验库」，历史版本布局继续保留。

## 验证

- `pnpm typecheck`：Core、世界包、Web 均通过。
- `pnpm test`：35 项 Core 测试及 7 项论坛测试通过。论坛覆盖多档案修改 / 切换 / 删除 / 重载、旧数据读取、损坏和禁用存储、中文分类映射、独立内容与回复搜索、浏览隔离、部署资源。
- `pnpm build`：完整构建通过。Windows 沙箱最初阻止子进程（spawn EPERM），改用正常执行权限重跑相同检查后通过。
- 真实浏览器：新增与改名后刷新仍保留全部字段；跨域浏览不修改档案；未开放世界说明；回复全文搜索；4 → 8 楼展开；公开标题勘误链接；夜间刷新恢复；390px 手机护眼无横向页面溢出。
- 手机分类弹窗的七个链接均可见；删除确认显示当前档案名，取消后保留数据；切回旧档案后重载保持选择。控制台零警告、零错误。
- GitHub 新帖入口抵达登录页，返回地址保留所选中文分类。未发布测试帖子，也未代填投稿授权。

CI / Pages 的最终结果以对应提交的 Actions 记录为准；交付时另核对 live URL 与最终提交。
