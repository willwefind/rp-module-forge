# Product Definition V0

## Product

RP Module Forge is an open-source modular assistance-system builder for AIRP and text roleplay.

The output is a portable **in-world assistance system** that can be injected into an RP session.

## Core flow

1. Choose world pack
2. Choose character identity / position
3. Review recommended capabilities
4. Add or remove capability modules
5. Add optional expert reasoning packs
6. Configure runtime behavior
7. Add current-session patch/context
8. Export one or more formats

## V0 outputs

- One-line invocation
- Compact injection prompt
- Full setting + injection prompt
- Manifest

## Non-goals for V0

- no account system
- no cloud database
- no API-key relay
- no model proxy
- no automatic reading of private chats
- no live AI generation inside the Forge

## V0 success condition

A user can create useful Ancient-China modules for substantially different roles
(e.g. emperor, general and servant) without rewriting the system from scratch.
