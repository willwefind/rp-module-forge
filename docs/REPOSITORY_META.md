## Short project introduction

```text
RP Module Forge is an open-source visual builder for assistance systems used in AI and text roleplay. It combines world-aware presentation with identity-based permissions, generic reasoning capabilities, optional expert lenses, Traveler Forum knowledge, and portable runtime rules—without granting omniscience or taking decisions away from the host character.
```
