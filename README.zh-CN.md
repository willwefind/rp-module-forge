# RP Module Forge

一个面向 AIRP 与文本 RP 的开源模块化辅助系统生成器。

它不是角色卡生成器，也不只是普通 Prompt 生成器。用户通过可视化装配：

- 世界观适配包
- 身份 / 权限适配器
- 能力模块
- 专家认知包
- 历代穿越者批注
- 系统运行规则

然后用同一份配置导出：

1. 一句话调用版
2. 简版注入 Prompt
3. 完整设定 + 注入 Prompt
4. Manifest 配置文件

首个官方内容包为 **中国古代 Ancient China Pack**。

> 核心原则：系统不全知。模块提高的是分析、发现矛盾、组织证据与推演后果的能力，而不是凭空获得当前世界的事实。

## 产品形态

- **Web App**：主产品
- **SillyTavern Extension**：第一方官方适配器
- 未来可扩展浏览器插件、MCP 或其他 RP 平台

所有入口共用同一套 core 与 Prompt Engine，避免多套逻辑长期分叉。
