# Contributing

Thanks for helping build RP Module Forge.

## Good contribution targets

- new world packs
- new roles / identity adapters
- new capability modules
- expert reasoning packs
- prompt-output improvements
- UI / accessibility
- SillyTavern integration

## Design rules

1. No omniscience by default.
2. Identity controls permissions.
3. Experts are reasoning lenses, not possession or personality overwrite.
4. The host makes final major decisions.
5. Web and integrations reuse the same core logic.
6. Never include API keys or private RP logs.
